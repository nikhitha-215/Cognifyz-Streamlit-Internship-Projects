# 🚀 Cognifyz Python Streamlit Internship Project Suite

A collection of 6 professional, enterprise-grade single-file Python web applications developed as part of the Cognifyz Technologies Internship. Built using **Streamlit** with a clean corporate light theme, high-contrast typography, and intuitive user experiences.

---

## 📁 Project Directory & Modules

| Task ID | Project Name | Source File | Description |
| :--- | :--- | :--- | :--- |
| **Task 1** | Interactive Quiz Game | `task1_quiz_game.py` | Dynamic trivia evaluation with real-time scoring and instant feedback. |
| **Task 2** | Number Pattern Generator | `task2_number_patterns.py` | Customizable mathematical pyramid and sequence rendering engine. |
| **Task 3** | Enterprise Task Management Suite | `task3_crud_app.py` | Full CRUD task management with search filters, priority levels, and live metrics. |
| **Task 4** | Thermal Engineering Suite | `task4_temp_converter.py` | Precision temperature conversion matrix with thermal state analysis and session history. |
| **Task 5** | Password Security Suite | `task5_password_checker.py` | Cryptographic strength heuristic evaluator and secure randomized key generator. |
| **Task 6** | Cognifyz Portfolio Hub | `task6_portfolio_hub.py` | Centralized master dashboard summarizing all internship deliverables. |

---

## 🛠️ Technical Stack
* **Language:** Python 3.x
* **Framework:** Streamlit
* **Styling:** Custom Corporate Light Theme (High-contrast typography, responsive layout matrices, custom CSS UI components)

---

## ⚙️ Quick Execution Guide

To run any of the individual applications locally on your machine, clone this repository and use the following command structure in your terminal:

```bash
# Clone the repository
git clone [https://github.com/nikhitha-215/Cognifyz-Streamlit-Internship-Projects.git](https://github.com/nikhitha-215/Cognifyz-Streamlit-Internship-Projects.git)
cd Cognifyz-Streamlit-Internship-Projects

# Run any module via Streamlit
python -m streamlit run task6_portfolio_hub.py
